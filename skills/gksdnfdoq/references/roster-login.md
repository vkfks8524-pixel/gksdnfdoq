# 명렬 기반 학생 로그인과 교사 학년·반 목록

Apps Script 수업용 웹앱에서 교사·학생 화면을 분리하고 스킬의 기본 시작 화면을 적용할 때 읽는다. 사용자가 명확히 요청한 다른 구성이 있으면 그 요청을 우선한다.

## 명렬의 구조

연결된 Google 스프레드시트에서 정확히 `명렬`이라는 이름의 탭을 사용한다.

웹앱이 열릴 때 [시트 초기화 규칙](spreadsheet-lifecycle.md)에 따라 없는 탭과 헤더를 준비한다. 기존 명렬과 학생 데이터가 있으면 보존하고 재생성하지 않는다.

| 위치 | 내용 |
| --- | --- |
| A1 | `학번` |
| B1 | `이름` |
| A2:B 이후 | 각 학생의 학번과 이름이 같은 행에 배치된 데이터 |

- 1행은 헤더로 취급하고, 조회·검증은 2행부터 한다.
- A열의 학번과 B열의 이름을 한 행의 학생 정보로 다룬다. C열 이후에 다른 데이터가 있어도 보존한다.
- 이 탭이 학생 입력정보 확인과 학년·반 목록 구성의 공통 기준이다. 별도의 학생 목록이나 고정 학급 목록을 만들어 기준을 나누지 않는다.

## 학번 해석

학번은 정확히 5자리 숫자다. 학번 전체는 식별자 문자열로 유지하고, 다음 위치별로 해석한다.

| 위치 | 의미 | `10101`의 값 |
| --- | --- | --- |
| 첫 1자리 | 학년 | `1` → 1학년 |
| 다음 2자리 | 반 | `01` → 1반 |
| 마지막 2자리 | 번호 | `01` → 1번 |

예를 들어 `31205`는 3학년 12반 5번이다. 반과 번호를 각각 1자리로 잘못 나누지 않는다.

- 사용자 입력과 시트 값을 비교할 때 문자열로 통일하고 앞뒤 공백을 제거한다. 시트에서 학번이 숫자로 읽혀도 동일한 5자리 문자열이면 같은 학번으로 처리한다.
- 문자열 전체가 숫자 5자리인지 확인한다. 잘못된 길이, 문자 혼합, 소수점 표기 등을 임의로 잘라내거나 0을 붙여 유효한 학번으로 만들지 않는다.
- 학년·반·번호를 표시하거나 정렬할 때에는 해당 부분을 숫자로 해석한다. 학년의 범위나 학급 수를 특정 학교급에 맞춰 고정하지 않는다.

## 학생 로그인

1. 첫 화면에 `학번`, `이름` 입력란과 로그인 동작을 제공한다. 이 기본 방식에 임의의 비밀번호나 Google 계정 로그인을 추가하지 않는다.
2. 입력 누락과 학번의 5자리 숫자 형식을 확인한다.
3. Apps Script 서버에서 명렬의 2행 이후 데이터를 읽어, 입력한 학번과 이름이 **동일한 행에서 모두 일치하는지** 검사한다. 이름도 앞뒤 공백을 제거한 뒤 정확히 일치하는지 비교한다. 부분 일치나 비슷한 이름으로 통과시키지 않는다.
4. 일치하는 행이 있으면 유효성 검사를 통과시킨다. 해당 행의 학번·이름과 학번에서 해석한 학년·반·번호를 학생 활동에 연결한다.
5. 일치하는 행이 없으면 로그인 화면에 머물게 하고 “학번과 이름을 다시 확인해 주세요.”와 같이 안내한다.

학번이 A열 어딘가에 있고 이름이 B열의 다른 행에 있다는 이유로 통과시키지 않는다. 예를 들어 한 행에 `10101 / 학생가`, 다른 행에 `10102 / 학생나`가 있다면 `10101 / 학생나` 입력은 실패해야 한다.

명렬 전체를 학생 브라우저에 내려보내 대조하지 않는다. 서버에서 검증하고, 클라이언트에는 성공한 학생의 활동에 필요한 최소 정보나 실패 결과만 반환한다. 교사 접근은 학생의 명렬 대조와 별개로 [교사 접근 방식](teacher-access.md)을 따른다.

## 교사 학년·반 드롭다운

기본값에서는 교사용 URL에 접속하면 바로 이 화면을 표시하고 교사 기능을 제공한다. 인터뷰에서 화면 진입용 비밀번호를 선택했다면 먼저 `설정!A1`과 대조하는 비밀번호 화면을 표시하고, 통과한 뒤 이 화면을 연다. 이 화면 이동을 Firebase 교사 권한 발급으로 연결하지 않는다.

1. 명렬 A열의 2행 이후 학번 중 정상적인 5자리 숫자 값을 해석한다. 헤더와 빈 행은 제외한다.
2. 학년의 중복을 제거하고 숫자순으로 정렬해 학년 드롭다운을 구성한다.
3. 학년별로 실제 존재하는 반의 중복을 제거하고 숫자순으로 정렬한다.
4. 선생님이 학년을 선택하면 그 학년에 있는 반만 반 드롭다운에 표시한다. 서로 다른 학년의 반을 합쳐 모든 학년에 똑같이 제공하지 않는다.
5. 학년을 바꾸면 이전 반 선택과 그 선택에 의존하는 화면 상태를 초기화하고, 새 학년에 맞는 반을 선택하게 한다.

예를 들어 명렬 학번이 `10101`, `10102`, `10201`, `20305`라면 다음 목록이 나온다.

| 학년 | 선택 가능한 반 |
| --- | --- |
| 1학년 | 1반, 2반 |
| 2학년 | 3반 |

교사 브라우저에는 드롭다운 구성에 필요한 학년·반 목록을 전달한다. 목록을 만들기 위해 전체 학생 이름을 전달할 필요는 없다.

## 명렬에 문제가 있을 때

- 명렬 탭이나 필수 헤더가 없으면 시작 시 초기화에서 안전하게 생성한다. 실제 학생 데이터가 비어 있으면 명렬 입력이 필요함을 안내한다. 로그인에 성공한 것처럼 처리하거나 임의의 학생·학급 데이터를 만들어 채우지 않는다.
- 헤더가 다른 위치에 있거나 기존 데이터 구조가 다르면 기존 자료를 임의로 덮어쓰지 않고, 확인된 구조와 필요한 조치를 설명한다.
- 잘못된 형식의 학번은 드롭다운에 섞거나 임의로 보정하지 않는다. 명렬의 데이터 오류를 교사가 확인할 수 있게 안내한다.
- 데이터가 없어 학년·반 목록을 만들 수 없으면 빈 상태와 원인을 표시한다. 하드코딩한 학급 목록으로 조용히 대체하지 않는다.
